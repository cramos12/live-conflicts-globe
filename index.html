Live Conflicts built on globe.gl

Source: GDELT 2.0 events — conflict reports machine-coded from world news, refreshed at the source every 15 minutes. This page's data file is rebuilt by a scheduled robot every ~30 minutes.

Each point is a place where news reports in the last ~60 minutes described an assault, a fight or armed clash, or mass violence. Point size grows with the number of reports. This is machine-coded news, not a verified battlefield feed — it can include ordinary crime and coding errors, and quiet places may simply have no coverage. If the feed cannot be loaded, this page shows no points rather than inventing any.
